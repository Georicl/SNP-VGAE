# SNP-VAE 预训练模块调参记录

## 一、改动背景

初始 SNP-VAE 实现存在以下问题：
1. **无 SNP 标准化**：不同 SNP 的基因型分布尺度差异大（MAF 高的方差大，MAF 低的方差小），高方差 SNP 主导 MSE 梯度
2. **β 固定不变**：β=0.01 从头到尾固定，训练初期易导致后验坍塌（posterior collapse）
3. **无学习率调度**：固定 lr=1e-3，后期在最优点附近震荡
4. **早停逻辑缺陷**：KL 退火期间 loss 上升是正常的（β 在增大），但早停把它当成"不再改善"

## 二、代码改动

### 2.1 `pretrain/preprocess.py` — SNP 行标准化

**改动**：在均值填充后，对每个 SNP（行）做 z-score 标准化：

```
x_std = (x - mean) / std
```

- 使每个 SNP 均值为 0、标准差为 1，消除尺度差异
- 返回 `(X, snp_mean, snp_std)` 三元组，`snp_mean` 和 `snp_std` 用于逆变换
- 新增 `inverse_standardize()` 函数，将标准化空间的重建值还原到原始 0/1/2 尺度

### 2.2 `pretrain/train.py` — KL 退火 + 学习率调度

**改动 1**：新增 `kl_warmup_epochs` 参数，β 从 0 线性增大到目标值：

```python
current_beta = beta * min(1.0, epoch / kl_warmup_epochs)
```

**改动 2**：退火期间不计入早停（防止 β 增大触发假早停）：

```python
if epoch < kl_warmup_epochs:
    # 退火阶段：只更新最佳状态，不增加耐心计数
    if avg_loss < best_loss:
        best_loss = avg_loss
        best_state = ...
elif avg_loss < best_loss:
    ...  # 正常早停逻辑
```

**改动 3**：新增 `ReduceLROnPlateau` 学习率调度器，当损失不再下降时自动降低学习率。

### 2.3 `test/test_real_data.py` — 评价增强

- 新增原始尺度重建评价（逆变换后对比 MSE 和逐 SNP 相关性）
- 新增 `--kl-warmup` 命令行参数
- 更新默认参数为实验最优值

所有实验均在 MPS (Apple Silicon GPU) 上运行，数据规模 9728 SNPs × 2002 samples。

## 五、网络宽度实验

### 背景

R5 达到 β=0.001 最优参数后，逐SNP相关性为 0.83，仍有 37% 低质量 SNP。
进一步分析发现低质量 SNP 均匀分布在各 MAF 区间（60% 来自 MAF>=0.2），
说明瓶颈不是低频 SNP 难重建，而是**网络容量不足**。

### 实验：增大嵌入维度 d_snp

| 实验 | d_snp | 相关性 | 低质量SNP | 标准化MSE | 活跃维度 |
|------|--------|--------|----------|----------|----------|
| R5基线 | 64 | 0.83 | 37% | 0.31 | 64/64 |
| R7 | 128 | 0.83 | 37% | 0.31 | 128/128 |

**结论**：增大 d_snp 无效，瓶颈不在嵌入维度。

### 实验：增大隐藏层宽度 hidden_dim

将网络从 `N→256→128→d_snp` 改为 `N→hidden→hidden/2→d_snp`。

| 实验 | hidden_dim | 参数量 | 相关性 | 低质量SNP | 标准化MSE | 训练耗时 |
|------|-----------|--------|--------|----------|----------|----------|
| 基线 | 256 | 1.1M | 0.83 | 37% | 0.31 | 36s |
| R8a | 512 | 2.4M | 0.89 | 14% | 0.20 | 40s |
| **R8b** | **1024** | **5.3M** | **0.94** | **3.9%** | **0.12** | 80s |

**结论**：网络宽度是关键瓶颈。hidden_dim=1024 时相关性达 0.94，低质量 SNP 仅 3.9%。

### 最终推荐配置

| 参数 | 最终默认值 |
|------|------------|
| β | 0.001 |
| lr | 5e-4 |
| patience | 50 |
| kl_warmup_epochs | 150 |
| batch_size | 512 |
| d_snp | 64 |
| **hidden_dim** | **1024** |

### 最终效果

| 指标 | 初始基线 | 最终配置 | 改善 |
|------|--------|--------|------|
| 逐SNP相关性 | 0.70 | **0.94** | +34% |
| 低质量SNP(<0.8) | 63% | **3.9%** | -94% |
| 标准化MSE | 0.48 | **0.12** | -75% |
| 活跃维度 | 15/64 | **64/64** | 全激活 |
| 原始尺度MSE | - | **0.04** | - |

## 六、关键发现

1. **SNP 标准化是必要的**：消除不同 MAF SNP 的尺度差异，让所有 SNP 在同一尺度上训练
2. **β 需要非常小**：对于基因型数据（值域 0/1/2），重建质量比隐空间正则化更重要
3. **KL 退火解决了后验坍塌**：让模型先学会重建，再逐步约束隐空间
4. **退火期间不能早停**：β 增大导致 loss 上升是正常的，必须等退火完成再启动早停计数
5. **β 越小重建越好，但隐空间越差**：需要在重建质量和隐空间质量之间找平衡
6. **网络宽度是关键瓶颈**：增大 d_snp 无效，增大 hidden_dim 效果显著（256→1024，相关性 0.83→0.94）
7. **低质量 SNP 并非集中在低 MAF**：均匀分布在各 MAF 区间，说明是模型容量问题而非数据问题
